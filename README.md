# 📖 What It Does

Smart Expense Tracker is a Django-based web application that helps users efficiently manage their personal finances by tracking income and expenses, organizing transactions into categories, and monitoring spending habits through an intuitive dashboard.

The application enables users to:

* Record income and expenses
* Categorize financial transactions
* Monitor monthly spending patterns
* Analyze expense distribution
* Maintain personal financial records securely
